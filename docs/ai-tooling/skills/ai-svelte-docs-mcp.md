# ai-svelte-docs-mcp

## Quando usar
Use este skill para Svelte/SvelteKit e quando precisar do MCP oficial do ecossistema Svelte.

## Fluxo
1. Usar `svelte` MCP remoto (`https://mcp.svelte.dev/mcp`) para consultas estruturadas.
2. Complementar com Context7 para bibliotecas relacionadas.
3. Confirmar detalhes de CLI e migrações na documentação oficial.

## Regras
- Antes de criar novos padrões, procurar convenções existentes no projeto.
- Em alterações de rota/formulário, incluir teste E2E de caminho feliz e erro.
