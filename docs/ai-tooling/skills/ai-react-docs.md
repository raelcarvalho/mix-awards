# ai-react-docs

## Quando usar
Use este skill para desenvolvimento React (componentes, hooks, estado, renderização, performance).

## Fluxo
1. Buscar docs atualizadas pelo Context7 para `react`, `react-dom` e libs auxiliares.
2. Confirmar padrões atuais no site oficial React.
3. Implementar com foco em componentes pequenos e previsíveis.
4. Validar com testes unitários/componentes e smoke E2E da tela alterada.

## Regras
- Evitar anti-patterns de estado derivado duplicado.
- Preferir composição e hooks customizados reutilizáveis.
- Em mudanças de UI, executar fluxo E2E mínimo com Playwright.
